# CANalyst audit and experiment log — October 30, 2026

The requested implementation, controls audit, model comparisons, and dashboard verification are complete. Observed attack-label parity with the control is verified on both development datasets, with measured model latency, full-capture detection and ingestion results, and interactive browser coverage. The evidence supports a functioning measured prototype; generalization, semantic faithfulness, and improved analyst performance remain research questions.

## Project understanding

Reviewed the complete midterm LaTeX report and extracted all 13 slides from the midterm PowerPoint, plus the repository, saved October 20/21 outputs, and Palmetto implementation guide. The original proposal described serving models in a Palmetto Slurm GPU job. The implemented experiment instead uses Clemson's RCD OpenAI-compatible LLM service. Those are distinct deployment paths. The current application runs ingestion, features, and detection locally; sends compact evidence to the selected model; and presents citations and saved comparisons in React.

The reported midterm performance is development evidence, not a pristine held-out test. The explanation experiment conditions on detected alerts, so it cannot establish recall for missed attacks. Valid citation IDs do not establish semantic support. The original report, presentation, and experiment outputs have been preserved.

Three parallel agents own controls/data, model/evidence integration, and frontend workflow. Root handles API integration, scientific scoring consistency, frozen corpora, latency measurement, and cross-review.

### Separate identifier-membership audit

`app/validation.py` checks explicit CAN-ID references in summaries, claims, affected-function descriptions, and recommendations against identifiers supplied in evidence. Canonicalization accepts case and zero-padding variants. Unqualified hexadecimal values are review notes, since they may be payload bytes, masks, or examples. Results appear in `validation_warnings`, with an explicit `validation_version`; neither field changes `grounded`, predictions, raw responses, or existing classification scores. Interactive cache identity includes the validator version.

`scripts.revalidate_identifiers` annotated all 100 existing GLM v4 replies offline without model calls or rewriting source artifacts. The separate annotations are `backend/out/validation_2026-10-30_v4/{hcrl,road}_glm.json` and carry exact source-run, corpus-file, canonical-corpus, per-record evidence, validator, and annotation-script hashes. Two explicit absent-ID references were found: HCRL corpus index 5, claim 3, `0x1A1`; ROAD index 6, summary, `0x55`. Nineteen additional ambiguous hexadecimal mentions require contextual review; they are not established errors. Sixteen responses have at least one note. The audit does not check causal entailment, numeric interpretation, or whether a valid ID is associated with the right measurement. Identifier-validity and citation-validity must therefore remain separate from semantic quality.

Nine identifier-validation regression cases (29 including explainer-integrity cases) passed, covering the `0x55`/`0x655` typo, case/padding equivalence, ambiguous payload hex, cache versioning, immutable saved outputs, and mismatched evidence rejection. The original model files and corpus files were hash-verified unchanged after annotation.
