Review rubric
  • Work independently. Wait until both reviews are complete before comparing notes.
  • For mixed claims, choose C if any part conflicts with evidence. Otherwise choose U if any part lacks support.
  • Check the arithmetic. Reasonable rounding and paraphrases are allowed.
  • Accept an inference when the cited numbers support it. Apply the same rule to hedged claims.
  • Practice example: “About twice baseline” is S when the cited value is 1.9x. “Twice baseline” is C for 1.5x.
